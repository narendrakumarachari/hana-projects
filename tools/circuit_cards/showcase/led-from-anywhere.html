Turn on an LED from anywhere in the world

A friend in another city, or another country, taps ON on their phone, and a light at your house switches on. You'll build it with an ESP32, a little Python web page, and a free "tunnel" app called ngrok.

Your mission, step by step

Tick each mission when it's done. Steps marked ESP32 or UNO are only for that version.

  1. Install the Arduino IDE and set File → Preferences → Sketchbook to HanaProjects\arduino.
  2. Set up Python. In a terminal:
    cd HanaProjects\python && python -m venv venv && venv\Scripts\activate && pip install -r requirements.txt
  3. ngrok: a grown-up makes a free account at ngrok.com, downloads ngrok, and runs ngrok config add-authtoken YOUR-TOKEN once.

On Hana's laptop all of this is already done. ngrok is in Downloads\04_TECHNOLOGY\Software\ngrok-v3-stable-windows-amd64.

  • ESP32 Nothing to build: the ESP32 has a blue LED on pin 2 already. Just plug in the USB cable.
  • UNO LED long leg → 220Ω resistor → pin ~11. LED short leg → GND. See the picture.
  1. ESP32 In the folder arduino\ESP32_WiFi_LED_WebAPI, copy arduino_secrets.example.h to arduino_secrets.h and type your Wi-Fi name and password. This file never goes online.
  2. Open the .ino file in the Arduino IDE. Choose the board: ESP32 ESP32 Dev Module or UNO Arduino Uno. Choose the Port, then click Upload (→).
  3. ESP32 Open the Serial Monitor at 9600 baud. Write down the address it prints, like 192.168.1.248.
  4. UNO Close the Serial Monitor. The Python program needs the USB port to itself.
  1. ESP32 Open python\03_Arduino_ESP32_Companions\web_esp32_led_control.py and change ESP32_IP = "..." to the address from Mission 3. Save.
  2. UNO In web_led_brightness_slider.py, check PORT = "COM5" matches Tools → Port.
  3. Run it (window 1):
    cd HanaProjects\python && venv\Scripts\activate && python 03_Arduino_ESP32_Companions\web_esp32_led_control.py
    For the Uno, use web_led_brightness_slider.py instead.
  4. Test it on the laptop: open http://127.0.0.1:5000 and press ON (or move the slider). The LED should react!
  1. Open a second window and go to the ngrok folder, then run:
    ngrok http 5000
  2. Find the Forwarding line. The https address on it is your world link:
ngrok (Ctrl+C to quit) Session Status online Region United States (us) Web Interface http://127.0.0.1:4040 Forwarding https://your-name.ngrok-free.dev -> http://localhost:5000

Your link stays the same every time. ngrok gives each free account one permanent address (it belongs to your account). Hana first used hers on 7 August 2026 to share ChirpQuest. Because it never changes, keep it as private as a house key.

  1. Open the world link on your own phone using mobile data (Wi-Fi off) to prove it works from outside.
  2. ngrok first shows a warning page. Tap Visit. That's normal for free ngrok links, and it won't appear again in that browser for 7 days.
  3. Send the link to a friend, or show the QR code below to your class. Because the link never changes, you can even print the QR code.

What's really happening?

🏠 Room number vs street address

Your laptop's Wi-Fi address (like 192.168.1.157) is like a room number inside your house: only people already inside can find it. ngrok gives it a street address (…ngrok-free.dev) that anyone in the world can visit, and walks visitors to your room.

📨 A button press is a message

Pressing ON sends a tiny web message, /on. It travels: phone → internet → ngrok → your laptop (port 5000) → Wi-Fi → ESP32. The ESP32 reads it and runs digitalWrite(LED, HIGH).

🚪 Why a tunnel?

Home routers block visitors from the internet to keep you safe. ngrok gets around this by having your laptop call out to ngrok first and keep that line open. Visitors come back through the same line.

Questions your class might ask

Could a hacker control my LED?

Only people who know your link, and only while ngrok is running. Your link stays the same, so never post it online, and always close ngrok after the demo.

Why is there an ngrok warning page?

Free ngrok links show it so people know they're visiting a site running on someone's computer. Tap "Visit" to continue.

Does it cost money?

No. ngrok's free plan, Python, Flask and the Arduino IDE are all free.

Could it control bigger things?

Yes: the same idea can switch a fan, open a door or feed a pet, using a relay module (with a grown-up, because mains electricity is dangerous).

If it doesn't work

What you seeWhat to do
"Can't reach the ESP32" under the buttonsThe ESP32 is off, on a different Wi-Fi, or ESP32_IP is wrong. Check its Serial Monitor for the address.
ESP32 Serial Monitor only prints dots .....The Wi-Fi name or password in arduino_secrets.h is wrong. The ESP32 only works on 2.4 GHz Wi-Fi.
"Could not open COM5" UNOClose the Arduino Serial Monitor, plug the Uno in, and check the COM number in Tools → Port.
ngrok says authentication failedRun ngrok config add-authtoken YOUR-TOKEN again (a grown-up finds the token on ngrok.com).
World link says the endpoint is offlinengrok isn't running. Run ngrok http 5000 again: your same link comes back to life.
Link opens but buttons do nothingWindow 1 (the web remote) was closed. Start it again. Both windows must stay open.
"Address already in use"An old copy is still running. Close all black windows and start again.

Safety rules

The link is a key

Only share it with people you know. Never post it on social media.

Close the tunnel

Always press Ctrl+C in ngrok when the demo is over.

Secrets stay secret

Never show or share your Wi-Fi password, arduino_secrets.h, or the ngrok token.

Grown-up for big stuff

LEDs only. Anything that plugs into the wall needs a grown-up.

Words to know

ESP32: a small computer board with Wi-Fi built in.
Web server: a program that sends web pages when someone asks.
Flask: the Python tool that makes our web server.
Port 5000: the "door number" our web server listens on.
IP address: a device's address on a network, like 192.168.1.248.
Tunnel: a private path that lets the internet reach your laptop.
ngrok: the free app that makes the tunnel and the world link.
Request: a message asking a server for something, like /on.
