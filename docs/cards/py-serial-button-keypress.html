Button → Keyboard (Python)

Listens to the Arduino. When the Arduino's button sends =, this program presses = on the computer keyboard.

PythonTalks to an Arduino over USB
1

How it connects

Wire and upload the board first: open its circuit card.

2

Run the program

Type in a terminal:cd HanaProjects\python && python 03_Arduino_ESP32_Companions\serial_button_to_keypress.py
  1. First time only: cd HanaProjects\python, then python -m venv venv and venv\Scripts\activate and pip install -r requirements.txt.
  2. Every time: venv\Scripts\activate (you'll see (venv) at the start of the line).
  3. Run the command above.
  4. Close the Arduino Serial Monitor first: only one program can use the USB port.
  5. Stop it with Ctrl + C.
3

Try it!

  1. Upload Button to Keyboard to the Uno and close the Serial Monitor.
  2. Run this program, open Calculator, type 2+2, then press the breadboard button.
!

If it doesn't work

Nothing happens

Check the COM port in the file (PORT = "COM5") matches Arduino IDE → Tools → Port.
