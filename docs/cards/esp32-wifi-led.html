ESP32 Wi-Fi LED

The ESP32 joins your Wi-Fi. Open a web address on a phone to turn its LED on and off.

★☆☆ Easy0 parts0 wiresBoard: ESP32 DevKit
⚡ ESP32 = 3.3 volts. Never connect 5V to an ESP32 pin. Everything on this card uses the 3V3 pin.

Upload the program

Open this file:HanaProjects\arduino\ESP32_WiFi_LED_WebAPI\ESP32_WiFi_LED_WebAPI.ino
  1. First time only: in the project folder, copy arduino_secrets.example.h to arduino_secrets.h and type your Wi-Fi name and password in it. This file never goes to GitHub.
  2. Plug the board into the computer with the USB cable.
  3. In the Arduino IDE: File → Open… → the file above.
  4. Tools → Board → esp32 → ESP32 Dev Module (install "esp32 by Espressif" in Boards Manager the first time).
  5. Tools → Port → the COM port that appears.
  6. Click Upload (the round → button) and wait for "Done uploading".
  7. Open Tools → Serial Monitor and set it to 9600 baud to see messages.

No extra libraries needed.

4

Try it!

  1. Open the Serial Monitor at 9600 baud and write down the IP address, e.g. 192.168.1.42.
  2. On a phone on the same Wi-Fi, open http://192.168.1.42/on, then /off, then /bird.

This project has a Python partner: ESP32 LED Web Remote (Python).

5

If it doesn't work

Stuck printing dots

The Wi-Fi name or password in arduino_secrets.h is wrong.

3.3V only!

The ESP32, the RFID reader and the colour screen are damaged by 5V.

Upload fails

Close the Serial Monitor, check Tools → Port, unplug and replug the USB cable, try again.
