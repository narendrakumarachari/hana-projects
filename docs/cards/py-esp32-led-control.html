ESP32 LED Web Remote (Python)

Makes a web page with ON, OFF and BIRD buttons that control the ESP32's LED over Wi-Fi. BIRD keeps it blinking.

PythonTalks to an ESP32 over Wi-Fi
1

How it connects

Wire and upload the board first: open its circuit card.

2

Run the program

Type in a terminal:cd HanaProjects\python && python 03_Arduino_ESP32_Companions\web_esp32_led_control.py
  1. First time only: cd HanaProjects\python, then python -m venv venv and venv\Scripts\activate and pip install -r requirements.txt.
  2. Every time: venv\Scripts\activate (you'll see (venv) at the start of the line).
  3. Run the command above.
  4. Stop it with Ctrl + C.
3

Try it!

  1. Upload ESP32 Wi-Fi LED and note its IP address.
  2. Put that IP in ESP32_IP = "..." at the top of this file.
  3. Run this program and open http://127.0.0.1:5000.
!

If it doesn't work

Buttons do nothing

The ESP32's IP address changed. Check it in the Serial Monitor.
