Screen Wiring Finder (tool)

If the colour screen stays dark, this tool tries the right wiring and 5 common mix-ups. The TEST number that lights up tells you what to fix.

★☆☆ Easy1 part10 wiresBoard: ESP32 DevKitUses a breadboard
⚡ ESP32 = 3.3 volts. Never connect 5V to an ESP32 pin. Everything on this card uses the 3V3 pin.
1

Get your parts

ESP32 DevKitthe brain
1.54" colour screen ST7789A small 240×240 full-colour screen. 3.3V only.
USB cableconnects the board to the computer
10 jumper wiresany colours work; matching the picture helps
Breadboardits + and − strips share power with every part
2

Look at the picture

Every wire has a colour and a number. Find the same number in the checklist. Parts get power from the breadboard's + strip (3V3) and − strip (GND).

3

Connect the wires, one at a time

Unplug the USB cable first. Tick each wire when it's in.

4

Upload the program

Open this file:HanaProjects\arduino\Tool_ST7789_WiringFinder\Tool_ST7789_WiringFinder.ino
  1. Plug the board into the computer with the USB cable.
  2. In the Arduino IDE: File → Open… → the file above.
  3. Tools → Board → esp32 → ESP32 Dev Module (install "esp32 by Espressif" in Boards Manager the first time).
  4. Tools → Port → the COM port that appears.
  5. Click Upload (the round → button) and wait for "Done uploading".
  6. Open Tools → Serial Monitor and set it to 115200 baud to see messages.
Libraries needed (Tools → Manage Libraries…, search, click Install). Already inside arduino/libraries if the sketchbook is set to HanaProjects\arduino:
  • Adafruit ST7735 and ST7789 Library (click Install All)
  • Adafruit GFX Library (comes with the one above)
5

Try it!

  1. Watch the screen: which TEST number shows up?
  2. Serial Monitor at 115200 baud says what that test means.
6

If it doesn't work

3.3V only!

The ESP32, the RFID reader and the colour screen are damaged by 5V.

Upload fails

Close the Serial Monitor, check Tools → Port, unplug and replug the USB cable, try again.
