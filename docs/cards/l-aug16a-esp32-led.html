Aug 16a · ESP32 Web LED

First Wi-Fi project: web addresses /on, /off and /PoP control an LED.

★☆☆ Easy1 part2 wiresBoard: ESP32 DevKit
⚡ ESP32 = 3.3 volts. Never connect 5V to an ESP32 pin. Everything on this card uses the 3V3 pin.
1

Get your parts

ESP32 DevKitthe brain
LED + 220ΩA tiny light. The long leg is +. Always use a 220Ω resistor so it doesn't burn out.
USB cableconnects the board to the computer
2 jumper wiresany colours work; matching the picture helps
2

Look at the picture

Every wire has a colour and a number. Find the same number in the checklist.

3

Connect the wires, one at a time

Unplug the USB cable first. Tick each wire when it's in.

4

Upload the program

Open this file:HanaProjects\arduino\SmartHouse_v1\Aug16a_ESP32_WiFi_LED_WebAPI\Aug16a_ESP32_WiFi_LED_WebAPI.ino
  1. First time only: in the project folder, copy arduino_secrets.example.h to arduino_secrets.h and type your Wi-Fi name and password in it. This file never goes to GitHub.
  2. Plug the board into the computer with the USB cable.
  3. In the Arduino IDE: File → Open… → the file above.
  4. Tools → Board → esp32 → ESP32 Dev Module (install "esp32 by Espressif" in Boards Manager the first time).
  5. Tools → Port → the COM port that appears.
  6. Click Upload (the round → button) and wait for "Done uploading".
  7. Open Tools → Serial Monitor and set it to 9600 baud to see messages.

No extra libraries needed.

5

Try it!

  1. Serial Monitor at 9600 shows the IP address. Open http://<IP>/on on a phone.
6

If it doesn't work

LED stays dark

Turn the LED around: the long leg goes toward the pin (through the resistor), the short leg to GND.

3.3V only!

The ESP32, the RFID reader and the colour screen are damaged by 5V.

Upload fails

Close the Serial Monitor, check Tools → Port, unplug and replug the USB cable, try again.

Program folder: arduino/SmartHouse_v1/Aug16a_ESP32_WiFi_LED_WebAPI (old name sketch_aug16a)Pins on this card are checked against the program code. To change a card, edit tools/circuit_cards/data.py and run python tools/circuit_cards/build.py.
