Button Door

Press a button and a motor opens a little door slowly, waits 5 seconds, then closes it.

★★☆ Medium2 parts5 wiresBoard: Arduino Uno
1

Get your parts

Arduino Unothe brain
Servo motor SG90Turns to an exact angle, 0° to 180°. Wires: brown = GND, red = 5V, orange = signal.
Push buttonConnects its legs while you press it. Use two legs on opposite corners.
USB cableconnects the board to the computer
5 jumper wiresany colours work; matching the picture helps
2

Look at the picture

Every wire has a colour and a number. Find the same number in the checklist.

3

Connect the wires, one at a time

Unplug the USB cable first. Tick each wire when it's in.

4

Upload the program

Open this file:HanaProjects\arduino\Door_Servo_ButtonOpen\Door_Servo_ButtonOpen.ino
  1. Plug the board into the computer with the USB cable.
  2. In the Arduino IDE: File → Open… → the file above.
  3. Tools → Board → Arduino Uno.
  4. Tools → Port → the COM port that appears.
  5. Click Upload (the round → button) and wait for "Done uploading".
  6. Open Tools → Serial Monitor and set it to 9600 baud to see messages.
Libraries needed (Tools → Manage Libraries…, search, click Install). Already inside arduino/libraries if the sketchbook is set to HanaProjects\arduino:
  • Servo by Michael Margolis, Arduino
5

Try it!

  1. Press the button. The door opens, waits 5 seconds and closes.
6

If it doesn't work

Servo shakes or resets the board

It needs more power: make sure it uses the 5V pin or strip, and all GNDs are connected.

Button does nothing

Buttons have 4 legs. Use two legs on opposite corners.

Upload fails

Close the Serial Monitor, check Tools → Port, unplug and replug the USB cable, try again.
