RFID Card Door Lock

Tap the right card and the door opens with a happy beep. A wrong card gets a warning buzz.

★★☆ Medium3 parts12 wiresBoard: Arduino Uno
1

Get your parts

Arduino Unothe brain
RFID reader RC522Reads ID cards and key tags. Uses 3.3V only!
Servo motor SG90Turns to an exact angle, 0° to 180°. Wires: brown = GND, red = 5V, orange = signal.
Passive buzzerCan play music notes with tone(). Long leg is +.
USB cableconnects the board to the computer
12 jumper wiresany colours work; matching the picture helps
2

Look at the picture

Every wire has a colour and a number. Find the same number in the checklist.

3

Connect the wires, one at a time

Unplug the USB cable first. Tick each wire when it's in.

4

Upload the program

Open this file:HanaProjects\arduino\Door_RFID_AccessControl\Door_RFID_AccessControl.ino
  1. Plug the board into the computer with the USB cable.
  2. In the Arduino IDE: File → Open… → the file above.
  3. Tools → Board → Arduino Uno.
  4. Tools → Port → the COM port that appears.
  5. Click Upload (the round → button) and wait for "Done uploading".
  6. Open Tools → Serial Monitor and set it to 9600 baud to see messages.
Libraries needed (Tools → Manage Libraries…, search, click Install). Already inside arduino/libraries if the sketchbook is set to HanaProjects\arduino:
  • MFRC522 by GithubCommunity
  • Servo by Michael Margolis, Arduino
5

Try it!

  1. Open the Serial Monitor at 9600 baud.
  2. Tap a card: the Serial Monitor shows its ID. Only the saved card opens the door.
6

If it doesn't work

RFID reader: 3.3V only

The RC522 is damaged by 5V. Use the Uno's 3.3V pin.

Add your own card

Copy the card ID from the Serial Monitor into authorizedUID in the program.

No sound

Check the buzzer's long leg (+) goes to the pin. A passive buzzer needs tone(); an active one beeps by itself.

Servo shakes or resets the board

It needs more power: make sure it uses the 5V pin or strip, and all GNDs are connected.

3.3V only!

The ESP32, the RFID reader and the colour screen are damaged by 5V.

Upload fails

Close the Serial Monitor, check Tools → Port, unplug and replug the USB cable, try again.
