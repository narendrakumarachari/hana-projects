Smart House

A model smart house: automatic door, temperature screen, night light, party mode with music, bedtime with an intruder alarm, and a mini game. You control it by typing commands.

★★★ Big build10 parts33 wiresBoard: Arduino UnoUses a breadboard
1

Get your parts

Arduino Unothe brain
16×2 LCD (I2C)Shows 2 lines of 16 letters, using just 2 data wires (SDA, SCL).
Temperature sensor DHT11Measures temperature and humidity.
Light sensor (LDR) + 10kΩChanges with light. Paired with a 10kΩ resistor so the Uno can read a number.
Door servo SG90Turns to an exact angle, 0° to 180°. Wires: brown = GND, red = 5V, orange = signal.
Distance sensor HC-SR04Sends a sound you can't hear and times the echo, like a bat.
RGB LEDThree lights (red, green, blue) in one. The longest leg is ground (−).
Night light LED + 220ΩA tiny light. The long leg is +. Always use a 220Ω resistor so it doesn't burn out.
Door buttonConnects its legs while you press it. Use two legs on opposite corners.
Passive buzzer (music)Can play music notes with tone(). Long leg is +.
Active buzzer (optional)Beeps one sound by itself when switched on. Long leg is +. Often has a sticker on top.
USB cableconnects the board to the computer
33 jumper wiresany colours work; matching the picture helps
Breadboardits + and − strips share power with every part
2

Look at the picture

Every wire has a colour and a number. Find the same number in the checklist. Parts get power from the breadboard's + strip (5V) and − strip (GND).

3

Connect the wires, one at a time

Unplug the USB cable first. Tick each wire when it's in.

4

Upload the program

Open this file:HanaProjects\arduino\SmartHouse_v1\SmartHouse_v1.ino
  1. Plug the board into the computer with the USB cable.
  2. In the Arduino IDE: File → Open… → the file above.
  3. Tools → Board → Arduino Uno.
  4. Tools → Port → the COM port that appears.
  5. Click Upload (the round → button) and wait for "Done uploading".
  6. Open Tools → Serial Monitor and set it to 9600 baud to see messages.
Libraries needed (Tools → Manage Libraries…, search, click Install). Already inside arduino/libraries if the sketchbook is set to HanaProjects\arduino:
  • LiquidCrystal I2C by Frank de Brabander
  • Servo by Michael Margolis, Arduino
  • DHT sensor library by Adafruit (click Install All)
5

Try it!

  1. Open the Serial Monitor at 9600 baud, line ending Newline.
  2. Type help, then try party, bedtime, gamemode, normal.
6

If it doesn't work

Big build: go slowly

Connect one part, test it, then add the next. The learning sketches in this folder test each part alone.

LED stays dark

Turn the LED around: the long leg goes toward the pin (through the resistor), the short leg to GND.

No sound

Check the buzzer's long leg (+) goes to the pin. A passive buzzer needs tone(); an active one beeps by itself.

Distance always 0

TRIG and ECHO may be swapped. Check them against the checklist.

Screen lights up but no words

Turn the small blue screw on the back of the screen. Still nothing? Run the I2C Scanner card: the address may be 0x3F.

Servo shakes or resets the board

It needs more power: make sure it uses the 5V pin or strip, and all GNDs are connected.
