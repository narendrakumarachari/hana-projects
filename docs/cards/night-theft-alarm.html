Night Theft Alarm

At night it turns on a street light and guards your object. In the day the alarm is off.

★★★ Big build4 parts15 wiresBoard: Arduino UnoUses a breadboard
1

Get your parts

Arduino Unothe brain
Light sensor (LDR) + 10kΩChanges with light. Paired with a 10kΩ resistor so the Uno can read a number.
Street light LED + 220ΩA tiny light. The long leg is +. Always use a 220Ω resistor so it doesn't burn out.
Distance sensor HC-SR04Sends a sound you can't hear and times the echo, like a bat.
Active buzzerBeeps one sound by itself when switched on. Long leg is +. Often has a sticker on top.
USB cableconnects the board to the computer
15 jumper wiresany colours work; matching the picture helps
Breadboardits + and − strips share power with every part
2

Look at the picture

Every wire has a colour and a number. Find the same number in the checklist. Parts get power from the breadboard's + strip (5V) and − strip (GND).

3

Connect the wires, one at a time

Unplug the USB cable first. Tick each wire when it's in.

4

Upload the program

Open this file:HanaProjects\arduino\Security_NightTheftAlarm\Security_NightTheftAlarm.ino
  1. Plug the board into the computer with the USB cable.
  2. In the Arduino IDE: File → Open… → the file above.
  3. Tools → Board → Arduino Uno.
  4. Tools → Port → the COM port that appears.
  5. Click Upload (the round → button) and wait for "Done uploading".
  6. Open Tools → Serial Monitor and set it to 9600 baud to see messages.

No extra libraries needed.

5

Try it!

  1. Cover the light sensor (night). Now take the object away: alarm!
6

If it doesn't work

LED stays dark

Turn the LED around: the long leg goes toward the pin (through the resistor), the short leg to GND.

No sound

Check the buzzer's long leg (+) goes to the pin. A passive buzzer needs tone(); an active one beeps by itself.

Distance always 0

TRIG and ECHO may be swapped. Check them against the checklist.

Upload fails

Close the Serial Monitor, check Tools → Port, unplug and replug the USB cable, try again.
