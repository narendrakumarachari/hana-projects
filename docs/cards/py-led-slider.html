LED Brightness Slider (Python)

A web page with a slider from 0 to 255. Moving it sends the number to the Arduino to set an LED's brightness on pin 11.

1

How it connects

Wire and upload the board first: open its circuit card.

2

Run the program

Type in a terminal:cd HanaProjects\python && python 03_Arduino_ESP32_Companions\web_led_brightness_slider.py
  1. First time only: cd HanaProjects\python, then python -m venv venv and venv\Scripts\activate and pip install -r requirements.txt.
  2. Every time: venv\Scripts\activate (you'll see (venv) at the start of the line).
  3. Run the command above.
  4. Close the Arduino Serial Monitor first: only one program can use the USB port.
  5. Stop it with Ctrl + C.
3

Try it!

  1. Upload LED Brightness from the Web to the Uno, then close the Serial Monitor.
  2. Run this program and open http://127.0.0.1:5000. Move the slider.
  3. Share it: double-click DEMO_LED_from_anywhere_Uno_slider.bat.
!

If it doesn't work

Could not open COM5

Close the Serial Monitor, plug in the Uno, and set PORT in the file to the COM number in Tools → Port.
