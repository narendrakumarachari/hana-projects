Jun 18d · Double Clap Tune

Clap twice quickly and it plays a little tune.

★★☆ Medium3 parts7 wiresBoard: Arduino Uno
1

Get your parts

Arduino Unothe brain
Sound sensorHears sound. DO says loud / quiet, AO gives a loudness number. Blue screw = sensitivity.
LED + 220ΩA tiny light. The long leg is +. Always use a 220Ω resistor so it doesn't burn out.
Passive buzzerCan play music notes with tone(). Long leg is +.
USB cableconnects the board to the computer
7 jumper wiresany colours work; matching the picture helps
2

Look at the picture

Every wire has a colour and a number. Find the same number in the checklist.

3

Connect the wires, one at a time

Unplug the USB cable first. Tick each wire when it's in.

4

Upload the program

Open this file:HanaProjects\arduino\SmartHouse_v1\Jun18d_Sound_DoubleClap_Melody\Jun18d_Sound_DoubleClap_Melody.ino
  1. Plug the board into the computer with the USB cable.
  2. In the Arduino IDE: File → Open… → the file above.
  3. Tools → Board → Arduino Uno.
  4. Tools → Port → the COM port that appears.
  5. Click Upload (the round → button) and wait for "Done uploading".
  6. Open Tools → Serial Monitor and set it to 9600 baud to see messages.

No extra libraries needed.

5

Try it!

  1. Clap twice within 1.5 seconds.
6

If it doesn't work

LED stays dark

Turn the LED around: the long leg goes toward the pin (through the resistor), the short leg to GND.

No sound

Check the buzzer's long leg (+) goes to the pin. A passive buzzer needs tone(); an active one beeps by itself.

Sensor always ON or always OFF

Turn the blue screw on the sensor until its little LED is just off when it's quiet.

Upload fails

Close the Serial Monitor, check Tools → Port, unplug and replug the USB cable, try again.
