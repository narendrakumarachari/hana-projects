Hana's Circuit Cards · ngrok guide

Share your project with the whole world

Any project that makes a web page on your laptop can become a link your friends can open from anywhere. The free app that does it is called ngrok. Here's how to use it, step by step.

Works with 5 of Hana's projectsFree10 minutes the first time1 minute after that

The steps

Steps 1–3 happen only once. After that, sharing takes one command.

  1. Go to dashboard.ngrok.com/signup and sign up (Google or email works).
  2. The grown-up owns the account and keeps the password safe.

✅ Already done for Hana's laptop.

  1. Easiest: open the Microsoft Store, search ngrok, click Get.
  2. Or: download the Windows zip from download.ngrok.com, then right-click it → Extract All. Inside is ngrok.exe.
  3. Check it works. Open a terminal and type:
    ngrok version
    You should see something like ngrok version 3.39.10.

✅ Already on Hana's laptop: Downloads\04_TECHNOLOGY\Software\ngrok-v3-stable-windows-amd64\ngrok.exe. In that folder, type .\ngrok instead of ngrok.

  1. The grown-up logs in and opens dashboard.ngrok.com/get-started/your-authtoken.
  2. Copy the long authtoken. It's like a password, so don't show it to anyone.
  3. In the terminal, type this, pasting the token instead of YOUR_TOKEN:
    ngrok config add-authtoken YOUR_TOKEN
  4. It answers "Authtoken saved to configuration file". Done forever on this laptop.

✅ Already done for Hana's laptop (saved in AppData\Local\ngrok\ngrok.yml, which must never be shared).

  1. Pick a project from the list below and start it in window 1. For example:
    cd HanaProjects\python && venv\Scripts\activate && python 04_ChirpQuest\chirpquest.py
  2. Check it works on the laptop first: open http://127.0.0.1:5000.
  3. Remember the port number: it's the number after the colon. All of Hana's web projects use 5000.
  1. Open a second terminal (window 2) and type:
    ngrok http 5000
    That means: "make a public web link that leads to port 5000 on this laptop."
  2. ngrok fills the window. Look for the line that says Forwarding:
ngrok (Ctrl+C to quit) Session Status online Account Grown-up's Name (Plan: Free) Forwarding https://your-name.ngrok-free.dev -> http://localhost:5000 Connections ttl opn rt1 rt5 p50 p90 0 0 0.00 0.00 0.00 0.00

The https://… address is your world link. It's your account's own free address, and it stays the same every time you run ngrok.

  1. Turn Wi-Fi off on your phone (use mobile data) and open the world link. If it works, it works for everyone!
  2. The first time, ngrok shows a warning page that says the site runs on ngrok. Tap Visit. It remembers for 7 days.
  3. Send the link to a friend, or make a QR code for it on the LED From Anywhere page.
  4. The Connections numbers in window 2 go up each time someone visits. To see every visit, the grown-up can open dashboard.ngrok.com/traffic-inspector.
  1. Click window 2 and press Ctrl + C. The link stops working right away.
  2. Press Ctrl + C in window 1 to stop your project.

Your link stays the same next time, so anyone who has it can visit again whenever ngrok is running. Treat it like a house key.

Steps follow ngrok's official quickstart: ngrok.com/docs/share-localhost/quickstart. Free-plan facts: ngrok.com/docs/pricing-limits/free-plan-limits.

Bonus: your link is also an API

An API is a link that programs can use, not just people. Your friend can switch on your LED from their own Python code:

import requests LINK = "https://your-name.ngrok-free.dev" # the world link you shared # the header skips ngrok's warning page for programs requests.get(LINK + "/on", headers={"ngrok-skip-browser-warning": "yes"})

Or from any terminal: curl -H "ngrok-skip-browser-warning: yes" https://your-name.ngrok-free.dev/on. Challenge: write a program that blinks your friend's LED 10 times!

Safety rules

Your link is a key

It never changes. Share it only with people you know. Never post it online.

Close the door

Ctrl+C in the ngrok window when you're finished.

The token is secret

Never share the authtoken or the ngrok.yml file.

Only share toys

Share LEDs, games and pages. Never share folders, files or anything private.
